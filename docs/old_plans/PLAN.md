## What the paper must show
1. Gesture-only control is unsafe in crowds: bystanders trigger it.
2. A per-person fuzzy engagement gate cuts bystander false triggers while keeping commander recall.
3. **IT2 beats Type-1 when perception is uncertain** (robot walking, occlusion, far, turned). This is the claim that makes it an ICAISC paper, so the data must contain enough uncertain cases to test it.

Claim integration novelty only (see CLAUDE.md: Muñoz-Salinas 2005 already did Type-1 fuzzy interest estimation).

## Dataset (the critical path)
| Item | Target |
|---|---|
| Participants | **≥ 8 different people**, rotating commander/bystander roles |
| Locations | 2 (Rysera lab + a corridor/lobby) |
| Takes | 9 scenarios (S1–S6, W1–W3) × ~4 reps ≈ **36–40 takes**, 60–90 s each |
| Episodes | **≥ 150 "not for robot"** and **≥ 150 "for robot"**, about half while walking |
| Distances | 1.5–4 m; some partly occluded and turning |
| Split | **dev** = dev1 + session-1 pilot takes (tune θ only here); **test** = everything else, never tuned on |
| Labels | 2 annotators label everything independently → report Cohen's κ; disagreements decided by a third |
| Ethics | signed one-line consent per person; blur faces in figures |

Instruction to bystanders: **gesture every ~5 s, hold 2 s, hands visible**. dev1 had only 2–3 bystander gestures, which was the weak point.

**Fallback if the dog's WebRTC link fails:** mount a phone or webcam on the dog at camera height, record with `--source webcam:N`, and drive with the remote or `--ip --drive`. Same pipeline, same metrics. Say so in the paper.

## Evaluation (all offline on logged features, so cheap to rerun)
- **Main table:** false-trigger rate and recall per policy, stationary vs walking, Wilson 95% CIs. **McNemar test** IT2 vs Type-1 on paired episodes.
- **Operating curve:** sweep θ_E and plot false triggers vs recall for all policies. Report false triggers at matched recall (e.g. 90%). Fairer than a single threshold.
- **Where IT2 helps:** split episodes by measured σ (low/high), occlusion and distance.
- **Robustness:** inject noise into logged distance/facing and show IT2 degrades less than Type-1.
- **Ablations:** facing only, distance only, no approach speed; head-only vs body-only facing; FOU scale k.
- **Learned baseline (optional, strong):** logistic regression on the same features, trained on dev only.
- **Closed loop:** unintended robot motions per minute during walking takes, IT2-driven.
- **Runtime:** fps on the laptop (and Jetson if you get one).

## Paper outline (~12 pages LNCS)
1. Introduction (1.5 p): bystander problem, 3 requirements, contributions
2. Related work (1.5 p): fuzzy engagement, addressee estimation, quadruped gesture HRI, IT2 under sensor noise
3. Method (3 p): perception + σ estimation, Layer 1 IT2 FLS (sets, rules, KM), Layer 2 decision, arbitration
4. Experimental setup (1.5 p): robot, participants, scenarios, labelling, metrics, dev/test split
5. Results (2.5 p): main table, operating curve, σ-bins, robustness, ablations, closed loop
6. Discussion and limitations (1 p): monocular distance, one site, small N, single dataset
7. Conclusion (0.5 p)

## Additions for the full version
- **Gaze input:** MediaPipe FaceLandmarker with iris landmarks on the face crop; gaze score = iris offset from eye centre combined with head yaw. σ_gaze grows as inter-ocular pixel distance shrinks (unreliable beyond ~2 m). Add gaze as a 4th Layer-1 input with its own uncertain-mean sets; extend the rules.
- **Raw video at full resolution:** run_live.py currently resizes to 960 px before saving raw.mp4. Save the original stream and resize only for processing, so gaze can be computed offline later.
- **Offline replay:** all features (including gaze) must be recomputable from raw.mp4, so recording never waits on code.
- **ROS-bag distance validation:** compare monocular distance + σ with LiDAR/RealSense distances on the team's `social_fusion` Go2 bag; fit σ_d(distance) from it; also count false accepts there (people walking past).
- **Extra ablation:** with vs without gaze, for Type-1 and IT2.
